# 国际物流全流程跟踪系统

面向**国际货运代理 / 外贸操作员**的工程项目全程跟踪桌面工具，核心定位为「**流程时间轴 + 节点内置单证清单提醒**」，让新手照界面操作即可不遗漏单证、快速理解业务流程。

> 当前状态：**可运行 Demo（代码骨架已搭建）**。核心流程（新建→甘特时间轴→单证提醒→归档）主线已可跑通，部分子模块待完善（见[开发计划](#-开发计划)）。

---

## 功能特性

- **国家模板驱动**：流程节点 / 泳道角色 / 默认单证清单按目的国模板生成。当前实现巴西（BR），模板集中配置，后续新增国家只改一处。
- **出口港子配置**：新建项目可选择出口港（当前支持「青岛港」与「通用方案」），选择港口仅影响国内段——自动为相关节点/单证追加该港口的线上办理平台备注，不改动节点结构与耗时。
- **12 节点流程时间轴（甘特图）**：出口报关 → 集港 → 捆扎 → 装船 → 海上运输 → 到港换单 → 进口许可 → 进口清关 → 海关查验 → 临时堆存 → 内陆运输 → 工地交付。含角色泳道标签、海运段自动压缩。
- **单证清单提醒**：每个节点内置"要求准备/提交的官方单证清单"，记录编制部门、份数、建议提交日、提交状态，逾期/遗漏自动预警。
- **纯本地运行**：数据存于本地 SQLite（`data/logistics.db`），无后端、可离线。
- 系统托盘常驻、今日待办去重弹窗、已完成项目只读归档。

## 测试 / 演示：可调"今日"时间

为便于测试和演示，主界面顶栏右侧提供了一个 **「测试时间」** 按钮（**仅用于开发/演示，交付前会移除**），用于临时改变全应用计算的"今日"日期，**无需修改系统时间**。

- 点击按钮 → 弹出日历，选择任意日期后点「应用」，全应用的「今日」即切换为该日期：
  - 主看板 / 甘特图的节点状态（进行中、逾期）
  - 单证清单的"临近提交日 / 超建议提交日"
  - 顶栏「今日待办」徽章与预警弹窗
- 点「恢复真实系统时间」即可回到真实系统日期。
- 处于模拟态时，按钮会变为红色并显示当前模拟日期，避免误判。

> 时间维度统一收敛在 `services/clock.py`（默认返回真实日期，可设置模拟日期）。全项目一律通过 `clock.get_today()` 取"今日"，不直接调 `date.today()`，因此切换时间会全局即时生效。**交付成品时**：删除顶栏该按钮与 `_change_time / _apply_clock_change` 方法，并将代码中 `get_today()` 改回 `date.today()`（或直接让 `clock.get_today()` 恒返回真实日期）即可。

## 数据模型

SQLite 单文件 `data/logistics.db`，四张表：

| 表 | 说明 |
| :--- | :--- |
| `projects` | 项目主表（名称 / 国家 / 出口港 / ETD / ETA / 缓冲天数 / 状态） |
| `nodes` | 流程节点（模板内序号 / 泳道角色 / 区域 / 耗时 / 计划起止 / 状态） |
| `files` | 单证清单（单证名 / 编制部门 / 份数 / 建议提交日 / 提交状态，核心表） |
| `settings` | 应用级设置 |

关键约定：所有日期统一 `YYYY-MM-DD`；每次写操作即时 `commit()`；国家/港口模板存于 `config.py`（DB 中不冗余），新增国家/港口仅改该文件。

## 开发文档

完整需求、数据模型、算法规范、Mock 数据、验收用例见 **[docs/开发文档_V6.md](./docs/开发文档_V6.md)**（PRD v6.2）。其中 Mock 数据 §15 与 `mock_data.py` 保持一致，可用于算法回归验证。

- 排程算法（§10）：境内段倒推至 ETD，海运段 ETD→ETA，境外段顺推，串行衔接。
- 节点状态机（§10.2）：`Pending / Active / Overdue / Done`，统一口径。

- 单证清单（§4.2）：覆盖装箱单、商业发票、进口证、熏蒸证书等实操单证，含编制部门/份数/一致性核查要求。
