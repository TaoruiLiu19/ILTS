# 国际物流全流程跟踪系统（ILTS）

面向**国际货运代理 / 外贸操作员**的工程项目全流程跟踪桌面工具，核心定位从「单证打勾的时间轴」升级为「**由货物 + 动态驱动的可重排时间轴**」：知道这批货是什么、从哪个港出发、船现在到哪、接下来怎么排。

> 纯本地离线运行（SQLite 存储，不接实时 AIS / 船司船期 / 在线地图 API）。

---

## 功能特性

### 出发国内港口查询与地图定位
- **港口权威数据单文件**：`services/ports_cn.py` 集中 40 个国内海港（名称/代码/省/港口群/首字母·拼音·别名/坐标/潮汐·吃水·引水·浮吊·库场 7 项资料/平台备注/横幅），按港口群分段注释排版，**人工可直接编辑**；`国内海港.md` 仅作参考资料。
- **新建页出发港下拉**：顶部固定 **“🚫 不指定特定港口平台（通用方案）”**（语义 `export_port=None`）并带分隔线，下方按港口群分组罗列 40 港，避免误选。
- **秒级检索**：支持中文名、**拼音首字母**（`TJ`→天津港、`NB`/`NBZ`→宁波舟山港）、全拼（`qingdao`）、UN/LOCODE 代码（`CNTAO`）、别名。
- **港口查询对话框**：左侧 港口群→省→港 树 + 搜索过滤；右侧**能力卡置顶**（浮吊吨位 / 航道吃水 / 库场情况，3 秒可扫），引水/代码次之，经纬度·潮汐折叠进“船务技术资料”。
- **地图定位组件 `PortMapView`**：QPainter 自绘中国沿海轮廓 + 40 个按港口群着色的定位点；选中/命中后目标点放大变红 + 呼吸灯、其余点灰显保位（“追光灯”）；支持港口群筛选可视化、悬停 Tooltip、单击地图点反选左侧列表（**辅助视觉确认，不把点图当主选港输入**）。
- **平台备注“可见即可得”**：选港后点“查看注入备注”，只读展示节点 1–4 的最终 remark——预览与保存共用 `services/ports.merge_node_notes` 同源函数，杜绝“预览一套、落库一套”。
- 校验/维护工具：`tools/gen_ports.py`（可选：从 md 一次性导入 / `--check` 数据完整性，容错缺失字段）。

### 流程 · 时间轴
- **国家模板驱动**：节点 / 泳道角色 / 默认单证按目的国模板生成（巴西 BR 12 节点）；新增国家改 `config.py` 即可。
- **12 节点甘特图**：出口报关 → 集港 → 捆扎固定 → 装船 → 海上运输 → 到港换单 → 进口许可 → 进口清关 → 海关查验 → 临时堆存 → 内陆运输 → 工地交付；含角色泳道、海运段自动压缩、今日金框定位。
- **海运表头单调去重**：海运压缩段的日期刻度从左到右严格递增、同一天只出现一次（边界日如 ETA 让位给境外段，不再两侧重复）。
- **甘特高亮**：海运「⚠ 最长段」（瓶颈）、节点 9/10 逾期提示「已耗缓冲 X 天」、台账超限件时节点③「吊装预警」。

### 甘特 ↔ 单证清单联动
- **悬停甘特节点**：行淡蓝高亮 + 就地弹出**单证速览卡**（必填/可选、建议日、状态）；单证清单展开时同步高亮并滚动到对应分组。
- **单击节点**：展开（若收起）单证清单并**钉住**该分组（高亮+定位）；再点同节点取消钉住并收起。

### 货物 · 班轮（台账与动态）
- **货物台账**：尺寸/毛重/包装/唛头逐项录入，单件 **>100t 或单边 >36m 自动判超限**并触发节点③吊装预警；装箱后可补记箱号/封号。
- **班轮与船位**：1 项目 1 船（船名/航次/IMO/承运人/MMSI）；手工登记船位与实际 ETA 并本地留痕；实际 ETA 可一键联动重排境外段（离线，Provider 预留 AIS 扩展）。

### 时间 · 动态调整
- **全环节推迟 / 提前**：境内 1–4 联动 ETD 与海运 start；海运 5 联动 ETA 与境外全段并重算海运时长；境外 6–12 口岸整段平移。
- **四守卫**：提前不早于今日、已完成节点保护、链连续性（锚点不漂移）、位移历史可撤销（净位移可负）。
- **单证联动**：位移后锚在节点起止日的单证 due 自动重算。
- **自动完成**：某节点**必填单证全部提交且已过 plan_end** → 自动视为完成（逾期消失）；撤勾必填单证自动回退。

### 主看板布局
展开项目卡片：统计字牌 → **时间轴甘特（恒显）** → 可收纳「动态调整 · 推迟/提前」→ 台账/班轮按钮行 → 可收纳「单证清单」；两大块默认收起，点击标题开合，**内容变更（勾选单证/位移等）不改变开合状态**；展开状态跨页面记忆。

### 提醒与归档
- 今日待办（托盘徽章 + 今日待办对话框）、逾期/缓冲预警、单证超建议日与缺失提醒。
- 已完成项目归档：只读甘特查看；内置两批演示数据（进行中 + 已完成历史批次）。

### 日报 / 周报生成
- 启动页四卡（2×2）新增「生成报告」入口；侧栏导航亦新增「生成报告」独立页。
- **预览 → 生成两步（职责分离）**：先「预览报告」只渲染同源 HTML，满意后再点「生成」弹摘要确认框直接导出，两按钮互不自动触发。
- **Word(.docx) 优先、纯文本降级**：装了 `python-docx` 导出带标题/表格/红色逾期缺失的 docx；未装则导出同名 .txt 并以【逾期】/【缺失】标红。文件写 `data/reports/`（已入库 .gitignore）。
- 报告板块：总体概览（健康绿/黄/红）+ 未完成清单（缺证红标）+ 操作动态（日报到小时 / 周报按天分组）+ 未来待办（日报含周末提前预警；周报取下周自然周一~周日窗口）+ 智能摘要 +（周报）与上周对比 + 下周风险（实时读 cargo 当前值判超限）。
- 操作日志 `op_log`：在新建/位移/撤销/自动完成/提交撤交单证/船位/货物变更等关键动作埋点；文件提交审计覆盖（同日同表单只余最新有效，底稿全留）、位移当日净收敛、撤销单独成条。
- 编号 `RPT-YYYYMMDD-NNN` 按自然日独立重置；日期可回看任意历史日/周，头部标注「历史回溯数据」。

## 技术栈

| 层级 | 选型 |
| :-- | :-- |
| 语言 | Python（全局 3.12） |
| GUI | PySide6（Qt6） |
| 数据 | SQLite（标准库 `sqlite3`，`data/logistics.db`）+ 港口目录 `services/ports_cn.py` |
| 分层 | UI → services（目录/检索/算法/提醒）→ db（+config 模板） |
| 开发工具 | `pypinyin`（仅 gen_ports 导入 md 时需要，可选） |

> ⚠️ 本机装有多个 Python，请用全局 3.12：`py -3.12` 或 `E:\python\Python312\python.exe`。

## 运行方法

```powershell
py -3.12 app.py        # 首次自动建库并灌入两批演示数据
```

顶栏“测试时间”按钮可切换模拟“今日”，便于演示节点/单证预警与今日定位。

## 目录结构（仓库仅代码与 README）

```
app.py                      # 入口：初始化 DB + 演示数据 + 启动 GUI
config.py                   # 国家模板 + 出口港薄壳（内部指向 services/ports）
db.py                       # SQLite 数据层（项目/节点/单证/货物/班轮/船位/位移历史/op_log）
mock_data.py                # 演示数据（进行中批次）
mock_completed.py           # 演示数据（已完成历史批次）
services/
  ports_cn.py               # ★ 40 港权威数据（单一可编辑文件：含坐标/检索字段/7 项资料/平台备注）
  ports.py                  # 港口检索(首字母/拼音/代码) / get_port / merge_node_notes / 能力解析
  scheduler.py              # 排程 + shift_node 推迟/提前（四守卫）+ apply/undo（埋 node_shift/unshift）
  file_checklist.py         # 单证 bootstrap + due 计算
  node_status.py            # 节点状态机 + 必填齐·过期末自动完成（埋 node_done）
  oplog.py                  # ★ 操作日志统一入口（白名单/审计覆盖/位移当日净收敛）
  reporting.py              # ★ 报告聚合纯逻辑（概览/未完成/动态/待办/摘要/周对比/风险/blocks）
  report_exporter.py        # ★ docx(可选)/txt 导出 + 按日重置编号 RPT-…-NNN
  reminder.py / clock.py / cargo_check.py / vessel_status.py
tools/
  gen_ports.py              # 可选：md 一次性导入生成 ports_cn.py；--check 数据自检
ui/
  main_window.py            # 侧栏 + 顶栏(今日待办/测试时间) + 生成报告页
  map_geo.py                # 地图地理投影工具（轮廓/投影）
  dialogs.py                # 货物台账 / 班轮船位 / 今日待办 对话框（埋点）
  pages/                    # home(四卡) / dashboard / new_project(含港口查询对话框) / completed / report
  widgets/                  # gantt_grid、file_panel、node_popover(速览卡)、collapsible、
                            # port_map(地图定位组件)、mini_bar、icons、theme
```

> 仓库仅包含代码与 README；业务/设计文档（优化方案、港口查询设计、清关/海港说明、PDF 管理办法等）与运行时数据库仅保存在本地，不入库（见 `.gitignore`）。
