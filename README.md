# 国际物流全流程跟踪系统（ILTS）

面向**国际货运代理 / 外贸操作员**的工程项目全流程跟踪桌面工具，核心定位从「单证打勾的时间轴」升级为「**由货物 + 动态驱动的可重排时间轴**」：知道这批货是什么、船现在到哪、接下来怎么排。

> 当前版本 v6.4 · 纯本地离线运行（数据存本地 SQLite，不接实时 AIS / 船司船期）。

---

## 功能特性

### 流程 · 时间轴
- **国家模板驱动**：流程节点 / 泳道角色 / 默认单证清单按目的国模板生成（当前实现巴西 BR，12 节点）；后续新增国家只改 `config.py`。
- **出口港子配置**：可选出口港（当前支持青岛港 QD 与通用方案），自动为国内段相关节点/单证追加该港线上办理平台备注。
- **12 节点流程甘特图**：出口报关 → 集港 → 捆扎固定 → 装船 → 海上运输 → 到港换单 → 进口许可 → 进口清关 → 海关查验 → 临时堆存 → 内陆运输 → 工地交付。含角色泳道、海运段自动压缩、今日金框定位。
- **甘特高亮**：海运「⚠ 最长段」（瓶颈）、节点 9/10 逾期提示「已耗缓冲 X 天」、台账含超限件时节点③标「吊装预警」。
- **状态提醒**：节点逾期 / 今日截止 / 今日启动 + 单证必填缺失 / 超建议日，托盘今日待办与弹窗汇总。

### 货物 · 班轮（D1）
- **货物台账**：逐项登记设备名、数量、尺寸 L×W×H、毛重、包装、唛头；单件 **>100t 或单边 >36m 自动判超限**并触发节点③吊装预警；装箱后可补记**箱号 / 封号**。
- **班轮信息**：1 项目 1 船，记录船名 / 航次 / IMO / 承运人 / MMSI。
- **船位动态（手动 · 离线）**：登记船位 lat/lon、实际 ETA、备注并本地留痕（可回放）；`services/vessel_status.py` 保留 Provider 抽象，未来如需 AIS 只增实现类即可。

### 时间 · 动态调整（D2）
- **全环节推迟 / 提前**：任意节点可整体位移（正=推迟、负=提前），三条子链锚点分离：
  - 境内 1–4 → 联动 ETD 与海运 start；
  - 海运 5 → 联动 ETA 与境外全段，海运时长按 `eta − etd` 重算；
  - 境外 6–12 → 口岸操作整段平移。
- **四守卫**：提前不早于今日、已完成节点保护、链连续性（锚点不漂移）、位移历史可撤销（`shift_history` 留痕，净位移可负）。
- **单证联动**：位移后锚在 `node_start / node_end` 的单证 due 自动重算；甘特与看板同步刷新。
- **实际 ETA 联动**：登记的实际 ETA 与计划不一致时，可一键重排海运 + 境外全段。

### 主看板项目展开卡布局
展开项目卡片后自上而下为：统计字牌（进行中 / 逾期 / 缺单证 / 货物超限）→ **时间轴甘特（恒显）** → 可收纳的「动态调整 · 推迟/提前」→ 台账/班轮/撤销按钮行 → 可收纳的「单证清单」。除甘特外的两大内容块**默认收起**，点击标题行展开/收纳，状态在数据刷新后保持。

### 甘特 ↔ 单证清单联动
- **悬停甘特某节点**：该行淡蓝高亮，并就地弹出**单证速览卡**（该节点的必填/可选单证、建议提交日、提交状态）；单证清单处于展开状态时同步高亮并滚动到对应“节点 N”分组。
- **单击甘特某节点**：展开（若收起）单证清单并**钉住**该节点分组（高亮 + 定位）；再次单击同一节点取消钉住并收起。
- 单证清单收起时悬停不会强行展开，仅显示速览卡，不打断浏览。

## 技术栈

| 层级 | 选型 |
| :-- | :-- |
| 语言 | Python（全局 3.12） |
| GUI | PySide6（Qt6） |
| 数据 | SQLite（标准库 `sqlite3`，本地 `data/logistics.db`） |
| 分层 | UI → services（算法/提醒）→ db（+config 模板），UI 不直接写业务逻辑 |

> ⚠️ 本机装有多个 Python，请使用全局 3.12 运行（`E:\python\Python312\python.exe` 或 `py -3.12`）。

## 运行方法

```powershell
# 首次启动自动建库，数据库为空时灌入演示数据（青岛→巴西 Sepetiba，12 节点 + 单证清单）
py -3.12 app.py        # 或 E:\python\Python312\python.exe app.py
```

顶栏提供**模拟时钟**按钮（测试用）：可临时改"今日"以提前演示节点 / 单证预警，勾选"恢复真实系统时间"即复位。

### 演示数据（两批）
- **进行中**：青岛→巴西 Sepetiba 光伏组件，12 节点进行中，可用于测试看板 / 甘特 / 单证提醒 / 位移调整。
- **已完成**（历史批次）：青岛→巴西 Sepetiba（历史批次），节点全部 Done、单证全部 submitted，进入「已完成」列表，双击可查看**只读甘特**，用于验收"过去的项目"归档功能。

> 两批数据自动灌入无需手建；删除对应 `data/logistics.db*` 重启即可恢复。

## 目录结构（仓库内仅代码与 README）

```
app.py                      # 入口：初始化 DB + 灌入演示数据 + 启动 GUI
config.py                   # 国家模板 / 出口港子配置（唯一配置源）
db.py                       # SQLite 数据层（项目/节点/单证/货物/班轮/船位/位移历史）
mock_data.py                # 演示数据（青岛→巴西光伏组件，进行中）
mock_completed.py           # 演示数据（已完成：历史批次，节点 Done + 单证 submitted）
services/
  clock.py                  # 统一时钟（测试用可模拟日期）
  scheduler.py              # 排程 + shift_node 推迟/提前（四守卫） + apply/undo
  file_checklist.py         # 单证清单 bootstrap + due 计算/重算
  node_status.py            # 节点状态机
  reminder.py               # 提醒引擎（今日待办）
  cargo_check.py            # 货物超限判定（>100t / 单边>36m）
  vessel_status.py          # 船舶动态 Provider（离线 ManualProvider，预留 AIS）
ui/
  main_window.py            # 主窗口：侧栏导航 + 顶栏(今日待办)
  dialogs.py                # 货物台账 / 班轮·船位 对话框
  pages/                    # home / dashboard(主看板) / new_project / completed
  widgets/                  # 甘特、文件面板、节点速览卡、可收纳区块、迷你条
```

> 仓库仅包含代码与 README；业务规划文档（优化方案、清关/报关/海港说明、管理办法 PDF 等）保留在本地，不入库（见 `.gitignore`）。
